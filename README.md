# LanFileShare — 局域网 SMB 文件共享托盘应用

一个 Windows 桌面应用：启动后**自动在后台把本机所有磁盘通过 SMB 共享给局域网设备**，提供托盘图标显示运行状态，并支持安全停止。

_**安卓端推荐CX文件管理器搭配使用**_

---

## ⚠️ 重要安全提示（务必阅读）

本应用按需求实现了“弱口令 + 共享全部磁盘”的行为，这**本身存在严重安全隐患**，仅建议在**可信的家庭/内网**临时使用：

1. **弱口令**：固定账号 `root` / 密码 `123` 极易被破解。任何能访问该网络的设备都可以尝试登录。
2. **共享系统盘**：把 `C:\`（含 Windows 系统目录、用户配置）共享出去，一旦泄露可能被读取敏感信息甚至被植入后门。
3. **明文协议**：SMB 在不启用加密时传输内容不加密，建议仅在可信局域网使用。
4. **我在测试时发现一个良性bug：访问时盘符显示列表会显示用户已共享的目录，不影响体验，故不修复**
---

## 1. 技术方案说明

本应用**复用 Windows 自带的 SMB 服务**（`LanmanServer`，监听 445 端口），而不是自研 SMB 协议栈。原因：

- Windows 自带 SMB 服务稳定、兼容性好，`\\主机名\共享名` 可直接被 Windows 资源管理器、macOS、手机文件管理器访问；
- 避免与系统原有共享冲突、避免自研协议栈的 445 端口占用与实现复杂度。

应用的核心工作是自动编排：**确保 SMB 服务运行 → 创建本地账号 → 为每个磁盘创建共享**。

## 2. 启动方式

- 以**管理员权限**运行 `LanFileShare.exe`（清单已声明 `requireAdministrator`，双击会自动触发 UAC 提权）。
- 程序启动后**立即在后台静默完成初始化**（无需任何手动配置），并驻留系统托盘。
- 托盘图标用颜色表示状态：🟢 绿=运行中，🔴 红=失败，⚪ 灰=已停止。
- 双击托盘图标或右键选择“打开状态窗口”可查看实时日志与共享列表。

构建与运行：

```powershell
# 还原 + 编译
dotnet build -c Release

# 直接运行（会触发 UAC）
dotnet run -c Release

# 发布为单文件免运行时依赖（可选）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## 3. 共享范围

- 枚举本机所有**就绪的固定磁盘（Fixed）与可移动磁盘（Removable）**（如 `C:`、`D:`、U 盘等），为每个盘创建同名共享。
- 例如 `C:\` → 共享名 `C`，局域网内访问路径为 `\\<主机名或IP>\C`。
- 网络盘（映射盘）不纳入共享。
- 已存在的同名共享会被跳过，且**停止服务时不会删除这些非本程序创建的共享**。

## 4. 访问权限控制

- 认证账号：`root` / `123`（本地账号，由程序在首次运行时自动创建）。
- 共享级权限：对 root 授予 `FULL`（读/写）共享权限。
- 实际可访问范围还受 **NTFS 权限**约束：`root` 默认是普通用户，可读系统大部分公共文件，但**无法**读取其他用户的私有目录或受保护的系统文件。
- 如需“完全访问所有文件”，可把源码中 `SmbServiceManager.GrantFullSystemAccess` 置为 `true`（会把 root 加入 Administrators 组）——**极其危险，默认关闭**。

## 5. 异常处理

| 场景 | 处理方式 |
| --- | --- |
| 非管理员运行 | 启动前检查权限，提示“请以管理员身份运行”，状态置为失败 |
| Server 服务未运行 | 尝试自动启动该服务并等待就绪 |
| 端口 445 被占用 / 服务被禁用 | 捕获异常并给出明确提示（“端口 445 被占用 / 服务被禁用”） |
| 密码策略不允许 `123` | 捕获 `net user` 失败，提示密码策略原因 |
| 磁盘不存在 / 未就绪 | 跳过未就绪磁盘；一个都没有则报错 |
| 共享名已存在 | 跳过且不纳入清理范围 |
| 初始化中途失败 | 自动**回滚**已创建的共享与账号，避免留下半成品 |
| 日志 | 全部操作写入 `%LOCALAPPDATA%\LanFileShare\LanFileShare.log` |

## 6. 安全停止

- 托盘“停止 SMB 服务”或状态窗口“停止服务”：
  - 删除**本次运行**创建的共享；
  - 删除**本次运行**创建的本地账号 `root`；
  - **不触碰**用户原本就存在的共享或账号；
- “退出”会在退出前自动执行一次安全停止。

## 7. 目录结构

```
LanFileShare/
├─ LanFileShare.csproj         # 项目文件（net8.0-windows / WinForms）
├─ app.manifest                # 声明 requireAdministrator
├─ Program.cs                  # 入口
├─ SmbServiceManager.cs        # 核心：服务/账号/共享编排 + 回滚 + 日志
├─ TrayApplicationContext.cs   # 托盘图标与状态机
└─ StatusForm.cs               # 状态窗口
```

## 8. 备注

- 依赖：.NET 8 SDK（构建时）；发布为 self-contained 后目标机器无需安装 .NET。
- 首次运行会自动创建本地账号 `root`，密码 `123`。
- 若局域网设备无法访问，请检查 Windows 防火墙是否放行“文件和打印机共享”，以及是否处于“专用网络”。
